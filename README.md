# Tata Digital — Portfolio & Digital Studio Landing Page

Landing page resmi dan interaktif untuk **Tata Digital Portfolio Studio**. Dirancang dengan prinsip *human-crafted, anti-slop, modern, clean, dan performa tinggi* untuk mengubah pertanyaan *"Boleh minta CV?"* menjadi kontrak proyek nyata.

## ✨ Fitur Utama
- **Interactive Device Preview**: Sakelar tampilan Desktop dan Mobile langsung di browser.
- **Katalog Template Portofolio**: 5 template desain interaktif siap pakai (Creative, Agency, Minimalist, Editorial, Neo-Brutalist) dengan modal preview.
- **Simulasi & Kalkulator Investasi**: Kalkulator dinamis untuk mengestimasi omset dan titik impas (BEP) proyek digital.
- **Direct WhatsApp Conversion**: Tombol CTA dan pemesanan yang otomatis terhubung ke WhatsApp dengan pesan terformat.
- **Performa & Anti-Slop**: Tipografi Plus Jakarta Sans + Inter + JetBrains Mono, palet solid Crimson Red (`#FF1A1E`) dan Electric Cyan (`#00BAFF`), tanpa animasi berat atau elemen semu.

## 🛠️ Tech Stack
- HTML5 Semantik
- Tailwind CSS (via CDN)
- Google Fonts (`Plus Jakarta Sans`, `Inter`, `JetBrains Mono`)
- Vanilla JavaScript (Responsive Modal, Device Preview Toggle, ROI Calculator)
